## 原生 IP 能做什么，不能做什么

LightLayer 曼谷的卖点之一是 IP 归属地就在曼谷，且带双 ISP 属性。第三方测评对 Netflix、Disney+ 等流媒体做过解锁测试，结果不错，这也是它比同价位普通曼谷 VPS 贵一些的主要原因。

需要把预期说清楚：原生 IP 解决的是「IP 注册地与服务器所在地一致」这件事，对区域限定的流媒体、本地服务注册有帮助。它不解决平台账号的风控问题。有泰国商家在自己的帮助文档里明确写过，第三方网站的「IP 纯净度评分」并没有统一依据，TikTok 这类平台有自己的 IP 库和检测手段。买一台原生 IP 的服务器不等于账号就安全，把这一点想明白，才不会花冤枉钱。

IP 被封的情况也要提前知道。海外服务器 IP 如果因为使用方式违反中国相关法律法规，存在被国内网络屏蔽的可能，这类问题商家通常不承担。做面向国内用户的业务，最好预留换 IP 的预算。

## 国内访问延迟 127 ms，这个数字怎么看

第三方测评对 BKK-VG04 做过国内多点 ping，平均在 127 ms 左右。做纯泰国本地业务，这个数字无关紧要；做面向国内用户的站，127 ms 属于国际线路的正常范围，比新加坡、日本机房高一截，但比欧美机房低。

路由走向值得记一下：联通走 AS4837 直连新加坡再进曼谷，移动走 CMI 经香港转泰国，电信走 163 骨干到新加坡后转 NTT 经马来西亚入曼谷。三条线都要绕一次第三地，这是「国际线路」的典型特征。

如果你的用户主体在中国大陆，且对首屏速度敏感，可以在服务器前面套一层面向国内的加速产品，或者干脆选带 CN2 之类优化线路的机房。LightLayer 在其他地区有优化线路的产品，泰国这一档主打的是本地原生 IP，不是回国速度。

## 常见问题

**泰国云服务器需要备案吗？**
服务器物理位置在泰国，不涉及中国大陆的 ICP 备案。如果域名解析到境内节点或使用境内 CDN，那一部分另有要求。
